## Part 1: Data Analysis Diploma (~132 Hours · 7 Parts)

### 01. Excel (24 Hours · 8 Sessions)
- **Session 01**: Introduction — What is Data Analysis · Types of Data · Data Pipeline · Key Tools
- **Session 02**: Excel Basics — Excel Interface · Formulas · Core Functions
- **Session 03**: Descriptive Statistics Part 1 — Types of Data · Measures of Center · Histogram · KDE · Range · Std Deviation · Variance · IQR · Box Plot
- **Session 04**: Descriptive Statistics Part 2 — Handling Outliers · Z-Score · Covariance · Correlation · Statistics & Date/Time Functions
- **Session 05**: Advanced Functions — Lookup Functions (XLOOKUP, VLOOKUP) · Text Functions · Power Query Intro
- **Session 06**: Pivot Tables & Charts — Power Query (continued) · Pivot Table · Pivot Charts · Slicers & Timelines
- **Session 07**: Data Modeling with Power Pivot — Relationships · Star/Snowflake Schema · Fact vs Dimension Tables · Primary/Foreign Keys · Calendar Table
- **Session 08 (⭐ Capstone Project)**: Full Analysis Cycle + Comprehensive Dashboard covering all topics

---

### 02. Python Fundamentals (12 Hours · 4 Sessions)
- **Session 09 (S1)**: Python Basics — Programming Intro · Print · Escape Characters · Variables · Input · Math, Logical & Comparison Operators
- **Session 10 (S2)**: Control Flow — If Statements · Nested If · While Loop · Break · Continue · Functions Intro
- **Session 11 (S3)**: Data Structures — Lists · Tuples · Dictionaries · Sets · Indexing, Slicing & Comprehensions
- **Session 12 (S4)**: Python Functions, Loops & Strings — Functions (`def`, parameters, `return`, `*args`, `**kwargs`) · LEGB Scope Rule · Lambda, `map()`, `filter()` · For & Nested Loops · String Methods & Slicing (`[::-1]`)

---

### 03. Python Libraries (27 Hours)
- **NumPy (3 hrs)**: Introduction to Libraries · Memory Optimization · Data Types · Creating Arrays · Math Functions · Slicing & Indexing
- **Pandas S1**: Reading Data from Different Sources · Data Overview & DataFrames
- **Pandas S2**: Full Dataset Analysis from Kaggle · Group By · Pivot Table vs Group By · Handling Dates
- **Pandas S3**: Quiz (Full Analysis + Insights) · Outlier Detection · Handling Missing Values with `.fillna()`
- **Pandas S4**: Quiz · Creating DataFrames · `loc`/`iloc` Slicing · Handling Missing Values (`fillna`, `ffill`, `bfill`, `replace`)
- **Pandas S5**: Quiz · Group By in Detail · Pivot Table vs Pivot & Crosstab · Merge · Concat
- **Matplotlib (3 hrs)**: Complete Tutorial — All Chart Types & Customization
- **Seaborn (3 hrs)**: Complete Tutorial — Statistical Visualizations
- **Plotly (3 hrs)**: Complete Tutorial — Interactive & Dynamic Charts

---

### 04. Database (SQL) (33 Hours · 11 Sessions)
- **Session 01**: Introduction to Databases — File-based Systems · DB Systems · DBMS · Database Architecture · ERD Basics
- **Session 02**: ERD Deep Dive — Entities · Attributes · Relationships · Cardinality · Mapping · Schema Design · Normalization Basics
- **Session 03**: SQL Basics — Create Database/Table · Data Types · Insert · Update · Delete · Constraints · Primary/Foreign Key
- **Session 04**: Querying & Filtering — SELECT · WHERE · ORDER BY · TOP · DISTINCT · Logical Operators · Wildcards · GROUP BY · HAVING
- **Session 05**: Built-in Functions — Scalar Functions · Conversion Functions · CASE WHEN
- **Session 06**: Joins & Subqueries — SQL Joins · Self Join · Cross Join · Union · Subqueries · EXISTS · IN · Ranking Functions
- **Session 07**: Normalization — 1NF · 2NF · 3NF · Denormalization · Practical Database Design Problems
- **Session 08**: SQL Programming — Variables · IF · WHILE · User Defined Functions · Views · Dynamic SQL
- **Session 09**: Advanced SQL — Indexes · Merge Statement · Pivot Tables · Stored Procedures · Triggers · Transactions
- **Session 10**: Security & Maintenance — XML · Error Handling · Backup & Restore · SQL Jobs · Security · Users & Permissions · Performance Optimization
- **Session 11 (⭐ Capstone Project)**: ERD → Mapping → DDL → DML → Constraints → Joins → Procedures → Advanced Queries → Optimization

---

### 05. Power BI (27 Hours · 9 Sessions)
- **Session 01**: Power BI Fundamentals — Business Intelligence Intro · Power BI Components · Excel vs Power BI · Data Analyst Workflow · ETL Process
- **Session 02**: Data Preparation with Power Query — Power Query Editor · Data Cleaning · Handling Missing Values · Transformations · Merge & Append
- **Session 03**: Data Visualization — Visualization Principles · Choosing the Right Chart · Bar/Line/Pie Charts · Maps · KPI Cards · Slicers · Filters
- **Session 04**: DAX Fundamentals — Introduction to DAX · Calculated Columns vs Measures · Row vs Filter Context · SUM · AVERAGE · COUNTROWS · IF
- **Session 05**: Advanced DAX & Time Intelligence — CALCULATE · FILTER · ALL · SUMX · RANKX · TOTALYTD · SAMEPERIODLASTYEAR · DATEADD
- **Session 06**: Data Modeling & Optimization — Star Schema · Fact vs Dimension Tables · Relationships · Cardinality · Calendar Table
- **Session 07**: Dashboard Development — Professional Dashboards · Dynamic KPIs · Conditional Formatting · Drill Through · Bookmarks · Tooltips
- **Session 08**: Power BI Service — Publishing Reports · Workspaces · Sharing · Scheduled Refresh · Row-level Security (RLS) · Gateway Configuration
- **Session 09 (⭐ Capstone Project)**: Full Business Case: Excel + Power BI · Data Cleaning · Modeling · DAX Measures · KPI Analysis · Dashboard · Publish to Service

---

### 06. Tableau (3 Hours · 1 Session)
- **Session 01**: Introduction to Tableau — Tableau Desktop vs Tableau Public · Creating Dashboards · Key Differences from Power BI
- **Mentor Task**: Rebuild a Power BI Dashboard using Tableau and compare visualization workflows.

---

### 07. Web Scraping (3 Hours · 1 Session)
- **Session 01**: Web Scraping Fundamentals — What is Web Scraping · BeautifulSoup · Requests Library · Selenium · ParseHub · Web Extensions
- **Mentor Task**: Scrape real-world data, clean it, analyze it, and generate an insights dashboard.
