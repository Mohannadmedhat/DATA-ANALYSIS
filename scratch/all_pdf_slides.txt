The process of turning raw data into decisions that matter.

Data Analysis Fundamentals Session 01 24
SQL Queries & Filtering
Ask precise questions of your data using SQL.
Filtering Basics
▪ SELECT chooses which columns to view
▪ WHERE filters rows by a condition
▪ ORDER BY sorts the results
▪ LIMIT restricts the number of rows returned
SQL
SELECT customer_name, total_spent
FROM orders
WHERE total_spent > 500
ORDER BY total_spent DESC
LIMIT 10;

=== SLIDE 26 ===

Data Analysis Fundamentals Session 01 25
Aggregation & Joins
Summarize data and combine multiple tables together.
Aggregation Functions
▪ COUNT, SUM, AVG, MIN, MAX
▪ GROUP BY summarizes rows into categories
▪ HAVING filters aggregated results
SQL
SELECT region, COUNT(*) AS orders,
SUM(total_spent) AS revenue
FROM orders
JOIN customers
ON orders.customer_id
= customers.id
GROUP BY region;
